# Calculadora de lucro (Versão Inicial)
Bem-vindo(a) ao meu repositório! Este é o meu primeiro script prático desenvolvido em **Python**, criado no início da minha jornada de programação.

## Sobre o Projeto
O objetivo desta aplicação é calcular o lucro de um produto para um negócio de maquiagem de forma prática e rápida. O programa pede ao utilizador o valor de custo e o valor de venda de um item, calculando e exibindo a margem de lucro imediatamente no terminal.

## Tecnologias e Conceitos Utilizados
* **Python**
* Entrada de dados ('input()') e exibição de mensagens ('print()').
* Conversão de tipos de dados ('float') para a realização de cálculos matemáticos com decimais.
* Estruturas com decimais ('if/else') para avaliar se o produto gera lucro ou prejuízo.
* **VSCode** e **GitHub**.
